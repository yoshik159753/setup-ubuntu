[source,sh]
.ansible install
----
# ubuntu 23.04 の場合は初期状態でも最新のバージョンがインストールできる模様
sudo apt-get update && sudo apt-get install -y ansible

# 古いバージョンでは ppa を追加すると良い
# ref. http://docs.ansible.com/ansible/intro_installation.html
sudo apt-get update && sudo apt-get install -y software-properties-common
sudo apt-add-repository ppa:ansible/ansible
sudo apt-get update && sudo apt-get install -y ansible
----

[WARNING]
====
ubuntu 26.04 & Python 3.14 の環境では sudo の制御が変わったらしくパスワード入力で timeout する。
このため、実行時は素直に NOPASSWD を付与して回避することを推奨。(実施後の復元も含めて)

[source,sh]
----
echo "username ALL=(ALL) NOPASSWD: ALL" | sudo tee /etc/sudoers.d/90-nopasswd
----
====

[source,sh]
.usage
----
# 全体実行
ansible-playbook -i localhost, --connection local main.yml --ask-become-pass

# 途中から実行
ansible-playbook -i localhost, --connection local main.yml --ask-become-pass --start-at='rolename : taskname'

# 利用可能なタグを確認
ansible-playbook -i localhost, --connection local main.yml --list-tags

# 特定のタグのみ実行
ansible-playbook -i localhost, --connection local main.yml --ask-become-pass --tags git

# 複数のタグを指定
ansible-playbook -i localhost, --connection local main.yml --ask-become-pass --tags "git,nodejs,docker"
----

[WARNING]
====
dry run は非対応。
一部のリクエストが HEAD リクエストになり 405 Method Not Allowed になる。
(skip 対応の予定は未定)
====

== virtualbox で検証

=== 環境構築

* virtualbox で環境作成
** メモリは 4GB 以上を推奨
* 構築手順
** https://dev-tips.pleasurecode.jp/nix#_virtualbox

=== 実行

TIP: 改修時は virtualbox の共有フォルダ機能でディレクトリを共有して作業することを推奨

WARNING: ssh でやるなら VM 側でポートフォワーディングや NOPASSWD の設定を推奨

[source,sh]
----
# 全体実行
ansible-playbook -i "127.0.0.1," main.yml -e "ansible_port=2222"

# 特定のタグのみ実行
ansible-playbook -i "127.0.0.1," main.yml -e "ansible_port=2222" --tags git
----
